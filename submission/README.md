# Submission Support Files

This folder contains viva-support material prepared alongside the dissertation:

- `dissertation_viva_presentation.pptx`: submission-ready PowerPoint deck for the recorded viva.
- `viva_script.md`: timed speaking script for the recorded dissertation viva.
- `viva_recording_checklist.md`: short checklist for the recording and demo.

The PowerPoint file in this folder is the one to use for recording and submission support.
